# Security

Hydra has no released runtime or supported production deployment yet.

Use this repository's Security tab to report a vulnerability privately. Do not place credentials, private project data, or exploit details in a public Issue. If private reporting is unavailable, contact a repository maintainer privately before sharing sensitive details.

Repository hygiene checks and automated reviews provide evidence with specific coverage; they are not a guarantee of safety. Development must preserve project-specific evaluation criteria, protected checks, and applicable human decision boundaries.
