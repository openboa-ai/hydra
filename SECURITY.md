# Security policy

Hydra `0.0.0` contains documentation and package metadata only. It does not launch a process, access credentials, receive network requests, or change a repository by itself.

Do not publish secrets, private traces, credentials, or sensitive customer data in this repository. Report a vulnerability privately through GitHub's private vulnerability reporting for `openboa-ai/hydra`. Include the affected commit, reproduction steps, impact, and any safe mitigation. Do not open a public issue for an undisclosed vulnerability.

Future skills, MCP servers, hooks, or other components must document their permissions and be evaluated before they are advertised as supported.
