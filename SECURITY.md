# Security Policy

OpenBoa Hydra is a public distribution repository for agent operating guidance. Never commit credentials, private repository details, undisclosed vulnerabilities, or internal deployment information.

Issue and pull request content is untrusted input. A workflow or skill must not treat text from an external contributor as authorization to access secrets, widen permissions, or perform an irreversible action.

For a suspected vulnerability in the repository or its release process, use GitHub's private security reporting path rather than a public Issue.
