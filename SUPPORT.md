# Support status

Support is established by an observed installation and run, not by the existence of a manifest.

| Client | Status for `0.0.0` | What is needed next |
| --- | --- | --- |
| Codex | `not tested / not supported` | Install a pinned candidate and run a Hydra Eval task |
| Claude Code | `not tested / not supported` | Run the same task with a compatible adapter |
| Cursor | `not tested / not supported` | Run the same task with a compatible adapter |
| OpenCode | `not tested / not supported` | Run the same task with a compatible adapter |
| Hermes | `not tested / not supported` | Run the same task with a compatible adapter |

The package follows the official Agent Plugins interface. A client may support the interface while still not supporting a particular Hydra version or component.
